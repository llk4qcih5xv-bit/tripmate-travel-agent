# 旅伴 - AI 旅游攻略网站

一个可部署的中文旅行攻略网页。访客可填写目的地、日期、天数、同行人数、预算、兴趣和行程节奏；服务端调用 DeepSeek Responses API，并用联网搜索生成带来源的中文建议。攻略按天拆分为分钟级日程、优先级、步行与交通、排队与预约、当日费用、随身物品和弹性调整等独立区块；表格支持手机横向浏览。

## 本机直接使用

这台电脑上的本机版本已经配置 DeepSeek 密钥。网站服务运行时，在浏览器打开 `http://127.0.0.1:3000` 即可使用；若服务停止，双击 `启动旅伴.bat` 重新启动（需要 Node.js 20+）。

出于安全考虑，`.env` 私密配置文件不会放进源码压缩包。下载源码后，复制 `.env.example` 为 `.env`，在本机填写 `DEEPSEEK_API_KEY`，然后运行 `node server.mjs`。密钥只通过服务端环境变量或本机 `.env` 提供，不会送到访客浏览器。

网站默认使用 `deepseek-v4-pro`，因为 DeepSeek 官方文档说明 Responses API 内的 `web_search` 目前由该模型支持。模型可用 `DEEPSEEK_MODEL` 配置。联网搜索和模型用量可能会扣 DeepSeek API 账户余额；请设置用量告警/限制。

## 部署到公开网站

将本目录部署到支持 Node.js 20+ 的主机，启动命令为 `npm start`。主机需提供 `PORT` 环境变量并设置 `HOST=0.0.0.0`（Dockerfile 已设置）。上线时在主机的环境变量/密钥管理中添加 `DEEPSEEK_API_KEY`；不要上传本机 `.env`，也不要把真实密钥写进网页或代码库。配置 HTTPS 和域名后，任何人均可通过网址访问。

当前没有账号系统，也不会持久保存用户行程；访客提交的表单会发送给 DeepSeek API 生成回复。页面已提示不要填写证件号、联系方式等敏感信息。服务端内置轻量限流（每来源 IP 每 10 分钟最多 6 次），数据保存在单个进程内存中。面向大量公众时，建议增加共享限流器/机器人防护，并设置 API 预算上限与告警。通过反向代理部署时，应确认代理会安全设置来源 IP 请求头。

## 信息准确性

攻略使用联网搜索查找近期公开资料并返回可点击来源。具体酒店、餐厅菜单和门票价格必须链接到对应页面；网页未显示的金额会标为待确认，不用猜测价格范围代替。路线距离和排队时间在无法可靠核实时会明确说明。挂牌价、营业时间、天气及交通信息仍需出发前复核；本网站不会代为预订。

## 当前公网预览

当前分享地址通过 localhost.run 临时隧道连接到运行本网站的电脑。任何拿到链接的人都能打开；电脑、网站服务和隧道进程必须持续运行，免费临时域名会定期变化。此方式适合先公开试用；长期稳定运营需部署到常驻云主机或建立固定域名隧道。

## 固定网址部署（Render）

项目根目录的 `render.yaml` 已配置好 Render Web Service：Node.js、Singapore 区域、`/api/health` 健康检查，并将 `DEEPSEEK_API_KEY` 留作 Render 控制台里的私密环境变量。将项目提交到 GitHub 后，在 Render 控制台导入该仓库并创建 Blueprint；首次创建时在私密变量栏填写 DeepSeek 密钥，不要把 `.env` 提交到 GitHub。

Render 会为 Web Service 分配固定的 `onrender.com` 地址。免费实例闲置 15 分钟会休眠，下一位访客访问时通常需要约一分钟唤醒；如需始终在线，需要升级实例方案。
